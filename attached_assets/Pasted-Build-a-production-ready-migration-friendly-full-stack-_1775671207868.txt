Build a production-ready, migration-friendly full-stack web application called “EcoPlate AI” that helps users reduce food waste by suggesting recipes based on available ingredients.

---

🎯 Core Features

1. Accept user input via:
   
   - Text (ingredients)
   - Image upload (mock ingredient detection for now)

2. Process ingredients and generate:
   
   - Recipe suggestions
   - Missing ingredients

3. Display results in a clean UI

4. Include a sustainability message:
   “You helped reduce food waste by using available ingredients.”

---

🏗️ Tech Stack

Frontend:

- React (functional components + hooks)
- Axios for API calls

Backend:

- Python
- FastAPI
- Requests library

AI:

- Hugging Face Inference API (free model like google/flan-t5-base)

🔄 Application Flow

1. User inputs ingredients OR uploads image
2. If image:
   - Mock ingredient detection (return sample ingredients)
3. Send ingredients to backend
4. Backend:
   - Validate input
   - Generate AI prompt
   - Call Hugging Face API
   - Process response
5. Return structured JSON response
6. Frontend displays results

---

🔌 Backend Requirements

- Use FastAPI with modular architecture
- Enable CORS middleware
- Create endpoint: POST /recipes

Input:
{
"ingredients": "milk, bread, egg"
}

Output:
{
"recipes": "...",
"missing": ["butter", "pepper"]
}

---

🧠 AI Service Design

- Keep AI logic isolated in ai_service.py

- Use prompt:
  “Suggest 2 recipes using these ingredients: {ingredients}. Also list missing ingredients.”

- Handle:
  
  - API failure
  - Empty responses

- Provide fallback response if AI fails
